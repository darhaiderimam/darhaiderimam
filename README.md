## 💡 Core Philosophy

1. **Verification, Not Generation:** AI writing copy is solved. Knowing whether that copy violates ad platform policies or misses mandatory legal disclosures requires deterministic evaluation gates.
2. **The Zero-Credentials Wall:** Performance marketers shouldn't need enterprise OAuth approval to run an audit. Run locally on desktop CSV exports with zero cloud sync.
3. **Built for Agencies, Not Solo SaaS Founders:** Existing skill libraries cater to a solo founder marketing one product. Our tools are engineered for practitioners managing multi-client budgets, teams, and attribution.

## ⚡ Quick Install

```bash
# Load agency skills in Claude Code, Cursor, or your AI terminal:
npx skills add darhaiderimam/agencyskills

# Or audit an ad account export locally:
git clone https://github.com/darhaiderimam/adaudit.git
cd adaudit && python -m adaudit.cli analyze export.csv --target-cpa 30
```
